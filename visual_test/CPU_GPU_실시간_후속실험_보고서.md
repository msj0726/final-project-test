# YOLO 얼굴·자세 파이프라인: CPU 병렬화와 Apple GPU 실시간성

실행일: 2026-11-04. 이전 [6개 발표 영상 실험](YOLO_발표영상_실시간_실험_보고서.md)의 YOLO11n-pose + YOLO5Face `yolov5n-face`를 그대로 사용했다. 두 모델의 입력 크기 640px, 검출 신뢰도 0.5, 관절 신뢰도 0.5, 팔·손목 이동 판정식도 고정했다. 바꾼 것은 CPU 계산 스레드 수, 두 모델의 동시 실행 여부, 실행 장치뿐이다.

## 결론

**이 Apple M5에서는 두 모델을 MPS로 실행하면 30FPS 입력을 거의 전부 실시간 처리했다.** 6개 영상의 동일한 180초 구간에서 저장 영상 최대 처리량 68.88FPS, 30FPS 재생 출력 29.98FPS, 누락 3/5,400프레임(0.06%), 촬영 예정 시점부터 출력까지 지연 중앙값 27.05ms·95백분위 33.55ms·99백분위 34.77ms였다. CPU 1스레드 기준은 16.74FPS와 44.07% 누락이었다.

**시험한 CPU 스레드·동시 실행 조합만으로는 30FPS에 도달하지 못했다.** 짧은 선별 시험에서 가장 빠른 CPU 조합은 스레드 1개씩 얼굴·자세를 동시 실행한 25.92FPS였다. 스레드를 늘리면 무조건 빨라지는 작업이 아니며, CPU 사용량·후처리·두 추론 간 자원 경쟁이 함께 작용한다. 시험하지 않은 멀티프로세스 설계까지 불가능하다는 뜻은 아니다.

**실시간 처리 가능성과 행동 정확도는 별개다.** MPS의 저장 영상 5,400프레임에 대한 사람·얼굴 출력 여부, 팔 들기, 큰 손목 이동 판정은 기존 CPU와 전부 같았다. 따라서 장치 변경이 이 표본의 판정을 바꾸지는 않았지만, 이것만으로 판정이 옳다는 뜻은 아니다. 실제 발표 피드백 제품의 정확도는 아직 입증되지 않았다.

## 조건과 측정

- 하드웨어: macOS 26.1 Apple M5, RAM 16GB. PyTorch 2.15.0, OpenCV 5.0.0. MPS는 Apple GPU 실행 장치다.
- 원본: 익명화한 1080p·30FPS 발표 영상 6개. 각 영상의 20%·50%·80% 부근에서 10초씩, 총 18구간·180초·5,400프레임. MPS 본 실험과 기존 CPU 기준은 **같은 프레임**이다.
- 저장 영상 최대 속도: 디코딩 → 얼굴 추론 → 자세 추론 → 관절 추출·행동 계산. 두 모델을 순차 실행했다. 5프레임 예열 후 측정했다.
- 30FPS 재생: 구간별 촬영 시점 간격을 33.33ms로 모사하고, 최신 프레임 하나만 보존했다. 처리 중 들어온 과거 프레임은 덮어써 누락으로 셌다. `capture_to_output_ms`는 모사한 촬영 예정 시점부터 결과 출력까지의 시간이다. 실제 카메라 입력·화면 출력·네트워크 전송 시간은 포함하지 않는다.
- CPU 선별 시험은 같은 6개 영상의 같은 시간 중심점에서 **각 1초씩 총 18초·540프레임**을 사용했다. 본 실험의 180초와 길이·포함 프레임이 다르므로 CPU 선별 속도를 전체 구간에 대한 보장치로 해석하지 않는다. 선별 구성끼리는 동일한 540프레임을 사용했다.
- `threads`는 PyTorch의 CPU 내부 계산 스레드 수다. `병렬`은 얼굴·자세 추론을 별도 작업 스레드에서 동시에 실행한다는 뜻이다. 기존 기준의 `1스레드`에도 영상 읽기 생산자 스레드 등 다른 운영체제 스레드는 존재한다.

### 180초 본 실험

| 실행 | 저장 영상 최대 속도 | 30FPS 재생 결과 | 누락 | 출력 지연 중앙값 / 95백분위 / 99백분위 |
|---|---:|---:|---:|---:|
| CPU 1스레드, 순차 | 16.74FPS | 16.78FPS | 2,380/5,400 (44.07%) | 80.99 / 96.70 / 101.42ms |
| MPS 얼굴+자세, 순차 | **68.88FPS** | **29.98FPS** | **3/5,400 (0.06%)** | **27.05 / 33.55 / 34.77ms** |

MPS 저장 영상의 단계별 중앙값은 디코딩 0.55ms, 얼굴 7.40ms, 자세 4.87ms, 행동 계산 0.64ms, 전체 13.70ms이다. 재생 구간에서는 얼굴 11.10ms, 자세 7.89ms, 행동 계산 0.72ms였다. 저장 영상 속도의 약 4.1배 차이는 **이 실행 구성의 측정치**이며 다른 Mac이나 라이브 카메라의 속도 비율은 아니다. MPS 모델·입력 전송 및 GPU 동기화는 각 모델 단계 시간에 포함했다.

### 18초 CPU 선별 시험

|---|---:|---:|---:|

| 1스레드, 얼굴·자세 병렬 | **25.92FPS** | **26.11FPS** | 70/540 (12.96%) |
| 2스레드, 얼굴·자세 병렬 | 22.64FPS | 22.11FPS | 142/540 (26.30%) |

위 CPU 조합의 성능 순서는 단일 실행 결과다. 실행 순서·온도·백그라운드 부하를 교차 반복하지 않았으므로 몇 FPS의 작은 차이에 일반적 우열을 부여하지 않는다. 다만 이 시험의 네 조합은 모두 30FPS 입력보다 느리고 프레임을 버렸다.

## 정확도와 사용 적합성

| 대상 | 현재 근거 | 냉정한 판단 |
|---|---|---|
| 사람·관절 위치 | 앞선 CPU 실행의 별도 COCO 정답 이미지 450장 평가에서 YOLO 조합의 사람·관절 위치 일치 Precision 0.917, Recall 0.957, F1 **0.936**. 현재 6개 영상에서는 5,400/5,400프레임에 사람 출력이 있었다. | COCO의 위치 성능은 유의미하지만 발표 영상의 정확한 관절 위치 정답은 없다. `사람 출력 100%`는 위치 정확도 100%가 아니다. |
| 얼굴 위치 | 앞선 CPU 실행의 별도 Open Images 정답 이미지 450장 평가에서 YOLO5Face 박스 Precision 0.775, Recall 0.849, F1 **0.810**. 현재 영상에서는 얼굴 출력 312/5,400프레임(5.78%). | 발표 영상은 얼굴이 가려져 있고, 기존 검토에서 102개 출력은 발표자 외 인물에 있었다. `5.78%`를 얼굴 검출 Recall로 계산할 수 없다. 이 영상 조건에서는 발표자 얼굴 위치 기능을 유효하다고 판정할 근거가 없다. |
| 팔 들기 | 1초마다 검토한 176개 확정 표본, 양성 6개. MPS 30FPS 재생 TP 5 / FP 0 / FN 1, Precision 1.000, Recall 0.833, F1 **0.909**. | 단일 검토자·희소 양성·사후 라벨 수정이 섞인 **탐색 점수**다. 초기 라벨에서는 F1 0.727이었다. 제품 정확도로 일반화하면 안 된다. |
| 큰 손목 이동 | 174개 확정 표본, 양성 23개. MPS 재생 TP 16 / FP 2 / FN 7, Precision 0.889, Recall 0.696, F1 **0.780**. | 이 출력은 손목 상대 이동량의 규칙값이다. 의미 있는 발표 제스처와 얼굴·옷 만지기를 구별하지 않는다. 행동 시작·종료 정답도 없다. |

행동 점수는 [기존 실험의 수정 라벨](results/realtime_yolo/review_labels.json)을 그대로 재사용했다. 영상의 180개 검토 시점을 기준으로 한 점수이며 모든 프레임의 F1이 아니다. 수정 라벨은 모델 불일치를 본 뒤 재검토됐으므로 **새로운 독립 평가가 아니다**. MPS 오프라인과 CPU 오프라인은 동일한 5,400개 프레임의 `person_count`, `face_count`, `arm_raised`, `large_wrist_motion_proxy` 값이 전부 일치했다. 얼굴 박스 출력도 전부 일치했고, 사람 박스 11프레임과 관절 출력 49프레임에서는 반올림된 숫자가 일부 달랐다. MPS의 30FPS 재생에서 팔 들기 F1은 기존 CPU와 같고, 큰 손목 이동은 CPU의 잠정 0.810에서 0.780으로 달랐다. 프레임 선택 차이·양성 23개의 작은 표본 때문에 이 차이를 정확도 변화로 판단하지 않는다.

COCO·Open Images 이미지 점수도 앞선 실험에서 이미 확인한 평가 결과를 인용한 것이다. 이번 MPS 실행에 대해 새로운 정답 이미지 평가를 한 것처럼 해석하지 않는다.

MPS 재생에서는 오프라인 모델 출력으로 정의한 0.1초 이상 팔 들기 사건 9개와 손목 이동 사건 33개를 모두 한 번 이상 출력했다. 모델 출력 시작부터 재생 출력까지의 중앙값은 각각 22ms, 26ms였다. **사람이 주석한 실제 행동 시작 시각과의 지연은 측정하지 않았다.**

**판정:** 이 Mac에서 현재 코드를 이용한 *얼굴·자세 추론과 단순 행동 표시의 30FPS 시제품*에는 MPS 구성이 적합하다. `30FPS마다 결과가 하나도 빠지면 안 된다`는 엄격한 기준에는 3프레임 누락이 있어 아직 합격이라고 할 수 없다. 얼굴 가림이 있는 실제 영상에서 발표자 얼굴 기능, 의미 있는 제스처 인식, 발표 품질 점수 자동화에는 정확도 근거가 부족하다. 실제 카메라·더 긴 연속 운용·다른 발표 영상에서의 지연과 실패율, 모델 예측을 보지 않고 만든 시간별 행동 정답으로 재확인이 필요하다.
