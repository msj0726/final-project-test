사용자 확인 정답: 21–27초는 양손 정지 구간. 해당 30개 표본 중 현재 규칙의 정지 판정은 11개(21.6–23.8초, 2.2초 연속)뿐이다. 23.8–27.0초는 손목의 어깨 대비 이동이 임계값 0.04를 넘는 것으로 계산되어 false였다. 따라서 5초 사건 0건은 이 정답 구간의 명백한 누락이다. 임계값·손 연결·미세 움직임의 기여는 추가 확인이 필요하다.

MediaPipe는 한 손 이상 257/314프레임(81.8%), 두 손 81/314프레임(25.8%)에서 검출했다. 이 수치는 정확도나 발표자 손 검출 재현율이 아니다. 손을 찾더라도 발표자 몸통·어깨·양손 연결과 시간 이력이 있어야 정지를 계산한다. 손 추가로 판정 시간이 1.2초 늘었지만 정확도가 좋아졌다는 증거는 아니다.

얼굴 방향은 49.4초 중 42초가 정면 조건을 만족해 85.02%이다. 화면 속 청중을 보는지도 Y로 인정하는 사용자 기준과 이 수치는 같지 않다. 손·휴대폰에 가려진 얼굴에서도 특징점이 출력될 수 있어 가림 제외 전 값은 시선 접촉 점수로 사용할 수 없다.

물건 상호작용 후보는 0건. 손목 근처 검출 1건도 이력 부족으로 탈락했다. 따라서 휴대폰·컵·포장·펜을 들거나 만지는 행동 전체를 잡았다고 말할 수 없다. LLM 발표 관련성은 NOT_RUN이다.

새로 확인한 주요 실패: 뒤 사람이 등장하면 몸통 선택이 중단되고, MediaPipe의 손 두 개가 서로 다른 사람에게 속할 수 있다. 현재 손 연결은 화면 x좌표로 정렬하는 실험용 방식이다. confidence=1은 내부 존재 표시이며 보정된 신뢰도가 아니다. mp_pose_hand도 YOLO 몸통이 있을 때만 관절을 대체하므로 순수 MediaPipe 단독 성능이 아니다.

4. 기존 JSON에서 무엇이 늘었나

손 모델 추가만으로 기존 v2 JSON의 필드가 새로 생긴 것은 아니다. 동일한 필드에 들어가는 관찰 시간 등이 달라졌다. 처음의 단순 JSON과 비교하면 아래 정보가 이미 확장되어 있다.

  • schemaVersion·observationConfigVersion·시간 범위: 어떤 구조와 기준으로 계산했는지 추적.
  • coverageRatio·handCoverageRatio·bothWristsVisibleSeconds: 관찰 부족을 높은 점수나 정상 행동으로 오해하지 않기 위한 정보.
  • candidateEvents·evidence·evidenceRefs: 미확정 후보와 근거 구간을 연결하여 루브릭이 최종 판단하도록 분리.
  • unobservableIntervals·reasonCode: 왜 판정하지 못했는지 시간별로 설명.
  • interactionDiagnostics: 물건 후보가 없는 이유가 검출·이력·이동 중 어디에 있는지 진단.
  • contextJudgments·isScoringReady·limitations: LLM 미실행과 점수 보류를 명시.

7. 물건 모델 비교와 다음 결정

YOLOE-11s-seg-pf도 동일 표본에 CPU로 실행했다. iphone 56건·smartphone 43건처럼 휴대폰 후보를 냈지만, 컵은 beer glass·champagne flute 등으로 흔들렸고 옷·장신구 관련 다수 라벨도 출력했다. 박스별 정답 대응 없이 종류 출력 건수만으로 기존 YOLO11n-seg보다 낫다고 결론낼 수 없다. YOLOE는 이번에 라벨과 시간만 저장했으므로 위치 정확도와 후속 사건 생성 비교는 완료하지 못했다.

우선 수정 대상은 큰 모델 교체보다 발표자 고정 추적과 손-사람 연결이다. 손을 x좌표로 배정하지 않고 발표자 관절·영역과 연결한 뒤, 정지/가림/물건 접촉을 다시 확인해야 한다. 정지 0건은 손을 모은 구간의 미세 움직임·좌표 흔들림·이력 단절을 분리해 확인해야 하며 지금 임계값을 임의로 완화하면 안 된다.

발표 무관 물건은 영상 검출과 별개로 발표 문맥 또는 사용자 정답이 필요하다. 이번 영상의 컵·휴대폰·포장·펜이 모두 무관한 물건으로 의도된 것인지 확인 후 관련성 평가 정답을 정해야 한다.

이번 영상은 이전 영상과 다른 추가 확인 자료다. 그러나 전체 행동 정답 라벨이 없고, 이 결과를 본 이후 조정에 사용하면 미사용 최종 평가 영상으로 부를 수 없다. Precision·Recall·정확도는 계산하지 않았다. 최종 모델 교체는 보류한다.
