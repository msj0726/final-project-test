10 · 추가할 JSON과 추천 출력 구조

아래는 신규 설계안이며 현재 모델의 실측 출력이 아닙니다. 장면·시각·기존 집계값은 위 실제 구간을 바탕으로 했지만 새 필드의 상태값은 연결 전 예시입니다. 값이 없는 항목을 임의의 신뢰도·점수로 채우지 않았습니다.

필드현재 상태추가·확정 이유
gaze.coverageRatio, bothWristsVisibleSeconds, candidateEvents, isScoringReady실험에는 이미 존재 / 공용 계약 미반영분모·관찰 부족·후보와 확정 사건·채점 준비 상태 구분.

__PROPOSED_JSON__

위 예시의 빈 unobservableIntervals는 “전부 관찰했다”는 뜻이 아닙니다. unobservableIntervalsStatus: NOT_GENERATED로 구간 집계 미구현을 명시했습니다. 실제 적용 시에는 생성 완료 여부와 해당 기준을 명확히 해야 합니다. 근거 참조는 예시와 같은 같은 응답 내부 ID로 시작할 수 있으며, DB 외래키나 새 API endpoint를 곧바로 만들 필요는 없습니다.

LLM이 실행되면 같은 criterionKey·evidenceRefs에 대해 실행 상태와 판단을 기록합니다. 물건 이름·검출 신뢰도만으로 APPLIES를 만들지 않습니다. 발표와 관련 있는 물건이라도 얼굴 가림 기준은 별개로 평가합니다.
